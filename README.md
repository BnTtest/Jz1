# JOZY — Nutrition Coach

Landing page responsiva criada em HTML, CSS e JavaScript puro.

## Como usar

1. Abra `index.html` no navegador.
2. Em `script.js`, troque:
   `const WHATSAPP_NUMBER = "5511999999999";`
   pelo telefone real da Jozy, com DDI + DDD + número e somente dígitos.
3. Substitua `assets/jozy-placeholder.svg` por uma foto profissional da Jozy.
   - Você pode manter o mesmo nome do arquivo para não editar o HTML.
   - Para produção, prefira WebP ou AVIF e altere o caminho no HTML.
4. Ajuste links de Instagram/Facebook/TikTok no footer.
5. Troque `https://example.com/` no canonical, sitemap e JSON-LD pelo domínio real.

## Recursos incluídos

- Dark mode padrão + Light mode.
- PT-BR e EN-US sem recarregar a página.
- Preferências salvas no localStorage.
- Hero premium e responsivo.
- WhatsApp com mensagem pré-preenchida.
- Menu mobile.
- FAQ accordion.
- Animações de scroll com prefers-reduced-motion.
- Indicador de progresso.
- Botão voltar ao topo.
- Formulário visual.
- SEO básico, Open Graph, favicon, sitemap e robots.txt.
- Seção de depoimentos oculta enquanto não houver depoimentos reais.

## Importante

O formulário está pronto visualmente, mas ainda precisa ser conectado a um backend ou serviço de envio de e-mail.

## Foto temporária

As áreas destinadas à foto da Jozy usam temporariamente uma foto pública de demonstração carregada pela internet.
Antes de publicar o site, substitua a URL usada nas tags `<img>` de `index.html` pelas fotos reais da Jozy.
